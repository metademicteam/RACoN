Resource-Aware Collaborative Network

Pool your PCs for local-first AI inference.

RACoN runs one model across Windows and Ubuntu machines in the same cluster. Each computer keeps its own memory, and the scheduler splits the model's layers by each PC's free capacity. If a worker goes offline, its layers move back to the head PC.

What RACoN is

One cluster, two operating systems

Windows and Ubuntu workers enroll the same way, advertise the same RPC endpoint, and are scheduled by the same head. Mix desktop PCs and headless Ubuntu servers in one cluster.

Local-first desktop app

A native app with hardware telemetry, a scheduler lab, benchmark history and a chat panel. Everything runs on your machine by default. Ubuntu Server installs can run headless with racon --headless.

Honest metrics

Hardware that does not expose real numbers reports Unavailable instead of a made-up figure. Simulated results are labeled as simulated.

Safe by design

Workers run only allow-listed task types. Public API calls need an API key. Admin controls stay on loopback and are never published.

How it works

  1. Install on each PC: the Windows installer or the Ubuntu tarball/.deb. Both install per-user and need no administrator rights.
  2. Join the cluster over Tailscale. Windows and Ubuntu workers expose only a single Tailscale address for layer traffic.
  3. Serve the model on the head PC. It measures every device, including Linux workers, and assigns layers in proportion to free memory.
  4. Call the OpenAI-compatible API at racon.metademic.org/v1 with an API key.

Use the same llama.cpp release on every node: the RPC protocol checks versions between the head and workers. Layer traffic stays on Tailscale or a private LAN; only API requests cross the public internet. Multiple PCs do not form a single pooled RAM or VRAM space.

Ubuntu / Linux

RACoN for Ubuntu / Linux (x86_64)

Portable tarball with a per-user installer. Requires Ubuntu 24.04+ (glibc 2.38); the llama.cpp runtime ships with its own libraries.

v1.0.6 downloads and verifies the worker's model layer shard in the background, with progress in the Worker Agent log. It also includes the CPU + RPC load fix, session refresh, and portable CPU backends.

tar -xzf RACoN-linux-x86_64-v1.0.6.tar.gz
cd RACoN-linux-x86_64-v1.0.6
./install.sh          # desktop app, no root
racon                 # launch
racon --headless      # Ubuntu Server worker

Public API

An OpenAI-compatible gateway in front of the model. Any OpenAI client works with it.

curl https://racon.metademic.org/v1/chat/completions \
  -H "Authorization: Bearer rk_your_key" \
  -H "Content-Type: application/json" \
  -d '{"model":"gemma-3-1b","messages":[{"role":"user","content":"Hello"}],"max_tokens":64}'
  • Endpoints: /v1/chat/completions, /v1/completions, /v1/embeddings, /v1/models
  • Auth: Authorization: Bearer rk_… (keys are issued by the operator; only SHA-256 digests are stored)
  • Limits: 30 requests/min per client IP, 60 requests/min per key, max_tokens up to 2048
  • Errors: 401 bad key, 429 rate limit (see Retry-After), 503 model offline

Public workloads may be visible to the operator of the machine that runs them. Do not send personal, confidential, medical, financial or credential data.
